# คู่มือ MintCream Budget PWA — เว็บแอปบันทึกรายรับรายจ่าย & เป้าหมายโน้ตบุ๊ก

คู่มือฉบับสมบูรณ์สำหรับทำความเข้าใจสถาปัตยกรรม สูตรคำนวณ ตั้งค่า Firebase ให้ซิงก์ข้ามมือถือและคอมพิวเตอร์ Deploy ฟรี และทดสอบใช้งานด้วยตัวเองทีละขั้น

---

## 1. สรุปแผนสถาปัตยกรรม โครงสร้างข้อมูล และสูตรคำนวณหลัก

### 1.1 สถาปัตยกรรมโปรเจกต์ (Static ES Modules — ไม่ต้อง Build)

โปรเจกต์ทั้งหมดอยู่ในไฟล์ `mintcream-budget-pwa.zip` เมื่อแตกไฟล์ออกมาจะมีโครงสร้างดังนี้:

| ไฟล์ | หน้าที่หลัก |
| :--- | :--- |
| `index.html` | โครงสร้างหน้าเว็บแบบ Mobile-first (Bottom Nav + ปุ่ม `+` ลอยบนมือถือ / Sidebar ด้านซ้ายบนคอม) |
| `style.css` | ระบบสีพาสเทล **เขียวมิ้นต์–ครีม** (`#FFF9EF`, `#A8E6CF`, `#5BBF9F`, `#FFB7A5`, `#B5D8F7`, `#FFF1B8`, `#2F4F46`) ปุ่มสูงอย่างน้อย `44px` และรองรับ `prefers-reduced-motion` |
| `firebase-config.js` | **ไฟล์เดียวที่คุณต้องแก้ไข** เพื่อนำค่า Config จาก Firebase มาวาง (ถ้ายังไม่ใส่ แอปจะทำงานในโหมดบนเครื่องให้อัตโนมัติ) |
| `utils.js` | ฟังก์ชันคำนวณล้วน (เขตเวลา `Asia/Bangkok`, ปีอธิกสุรทิน, สัปดาห์เริ่มวันจันทร์, สูตรงบวันนี้, เครื่องคำนวณความเป็นไปได้, What-if, CSV) |
| `store.js` | ระบบเชื่อม Firebase Authentication (Google Sign-in) + Cloud Firestore แบบเรียลไทม์พร้อม Offline Persistence + ระบบสร้างรายการประจำอัตโนมัติ |
| `app.js` | ตัวควบคุมหน้าจอทั้งหมด 5 หน้า, Bottom Sheet บันทึกเร็ว, Undo Toast 5 วินาที, กราฟ Chart.js, Confetti เบา ๆ |
| `manifest.json` และ `sw.js` | ไฟล์ PWA สำหรับติดตั้งลงหน้าจอหลัก (มือถือ/คอม) และเปิดใช้งานแบบออฟไลน์ |
| `firestore.rules` | กติกาความปลอดภัย Firestore ที่อนุญาตเฉพาะเจ้าของบัญชี (`request.auth.uid == userId`) |
| `icons/` | ไอคอนแอป `icon-192.png`, `icon-512.png` และ `icon.svg` |

### 1.2 โครงสร้างฐานข้อมูล Cloud Firestore

ข้อมูลของผู้ใช้แต่ละคนจะถูกแยกเก็บอย่างเป็นส่วนตัวใต้ `users/{uid}` ดังนี้:

- `users/{uid}/transactions/{txId}` — เก็บรายการรายรับ (`income`), รายจ่าย (`expense`), และเงินออมเข้าเป้า (`savings`) พร้อม `date` (`YYYY-MM-DD`), `amount`, `categoryId`, `note`
- `users/{uid}/categories/{catId}` — เก็บหมวดหมู่ ไอคอน สีพาสเทล และสถิติการใช้งานล่าสุด (`usageCount`, `lastUsedAt`) เพื่อเรียงหมวดที่ใช้บ่อยมาไว้หน้าสุด
- `users/{uid}/recurring/{recId}` — เก็บรายรับประจำสัปดาห์ (`2,200 + 300` ทุกวันจันทร์) และรายจ่ายประจำรายเดือน (`AI 1,000`, `YouTube 130` ทุกวันที่ 1 พร้อมบันทึกเดือนที่จ่ายแล้วใน `paidMonths`)
- `users/{uid}/goals/main` — เก็บเป้าหมายโน้ตบุ๊ก (ชื่อเป้า, งบ, วันที่อยากได้ `2027-02-28`, เงินเก็บตั้งต้น `0`, รุ่นที่เลือกเป็นเป้าหมายหลัก, Milestones ที่ฉลองแล้ว)
- `users/{uid}/wishlist/{itemId}` — เก็บลิสต์รุ่นโน้ตบุ๊กที่สนใจ (ชื่อรุ่น, ราคา, สเปกสั้น ๆ, ลิงก์, โน้ต)
- `users/{uid}/settings/main` — เก็บค่าประมาณการงบ Shopee รายเดือน (`1,750`), ค่ากินเฉลี่ย/สัปดาห์ (`950`), ค่าน้ำมันเฉลี่ย/สัปดาห์ (`300`), และวันเริ่มสัปดาห์

### 1.3 สูตรคำนวณหลัก

1. **งบใช้ได้วันนี้ (Daily Safe Budget)** — สัปดาห์เริ่มวันจันทร์ถึงอาทิตย์:
   $$\text{งบใช้ได้วันนี้} = \frac{\text{รายรับคาดการณ์สัปดาห์นี้} - \text{เงินกันเก็บเป้าหมาย/สัปดาห์} - \text{ส่วนแบ่งรายจ่ายประจำและ Shopee/สัปดาห์} - \text{ที่ใช้จ่ายไปแล้วสัปดาห์นี้}}{\text{จำนวนวันที่เหลือในสัปดาห์ (รวมวันนี้)}}$$
   - หากผลลัพธ์ติดลบ แอปจะแสดงเป็น `฿0` พร้อมข้อความนุ่ม ๆ *"วันนี้พักก่อนนะ พรุ่งนี้ค่อยว่ากัน 🌿"* โดยไม่มีสีแดงหรือถ้อยคำตำหนิ
   - ส่วนแบ่งรายจ่ายประจำ + Shopee รายสัปดาห์ คำนวณจาก `(รายจ่ายประจำรายเดือนรวม + งบกัน Shopee รายเดือน) ÷ 4.345`

2. **เครื่องคำนวณความเป็นไปได้ & What-if**:
   - **เก็บได้จริงต่อสัปดาห์** = `รายรับต่อสัปดาห์ − ((รายจ่ายประจำต่อเดือน + งบ Shopee ต่อเดือน) ÷ 4.345) − ค่ากินเฉลี่ยต่อสัปดาห์ − ค่าน้ำมันเฉลี่ยต่อสัปดาห์`
   - **วันที่คาดว่าจะได้ซื้อโน้ตบุ๊ก** = `วันนี้ + ปัดขึ้น((งบเป้าหมาย − เงินเก็บสะสมปัจจุบัน) ÷ เก็บได้จริงต่อสัปดาห์ × 7)` วัน

## 2. คู่มือตั้งค่า Firebase ทีละขั้นสำหรับมือใหม่

> หากอยากลองเปิดเล่นดูก่อน สามารถเปิดเว็บใช้งานแบบเก็บข้อมูลบนเครื่องได้ทันทีโดยไม่ต้องทำขั้นตอนนี้ แต่หากต้องการให้ **มือถือและคอมพิวเตอร์เห็นข้อมูลเดียวกันแบบเรียลไทม์** ให้ทำตาม 6 ขั้นตอนนี้ครับ

### ขั้นที่ 1: สร้างโปรเจกต์ Firebase ฟรี
1. เปิดเว็บ [Firebase Console](https://console.firebase.google.com/) แล้วลงชื่อเข้าใช้ด้วยบัญชี Google ของคุณ
2. กดปุ่ม **Create a project** (สร้างโปรเจกต์) → ตั้งชื่อเช่น `mintcream-budget` → กด Continue
3. ปิด Google Analytics (ไม่จำเป็นต้องใช้) แล้วกด **Create project** รอจนสร้างเสร็จแล้วกด Continue

### ขั้นที่ 2: เปิดใช้งาน Google Sign-in
1. เมนูด้านซ้ายเลือก **Build → Authentication** → กด **Get started**
2. แท็บ **Sign-in method** → คลิก **Google**
3. เปิดสวิตช์ **Enable** → เลือกอีเมลในช่อง **Project support email** → กด **Save**

### ขั้นที่ 3: สร้างฐานข้อมูล Cloud Firestore
1. เมนูด้านซ้ายเลือก **Build → Firestore Database** → กด **Create database**
2. เลือกโซนเซิร์ฟเวอร์ใกล้ไทย เช่น **`asia-southeast1` (Singapore)** → กด Next
3. เลือก **Start in production mode** → กด **Create**

### ขั้นที่ 4: ใส่ Security Rules (แยกข้อมูลเฉพาะเจ้าของ)
1. ในหน้า Firestore Database ให้กดแท็บ **Rules** ด้านบน
2. ลบโค้ดเดิมทั้งหมด แล้วคัดลอกเนื้อหาจากไฟล์ `firestore.rules` ในโปรเจกต์ไปวาง:
   ```javascript
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /users/{userId}/{document=**} {
         allow read, write: if request.auth != null && request.auth.uid == userId;
       }
       match /{document=**} {
         allow read, write: if false;
       }
     }
   }
   ```
3. กดปุ่ม **Publish**

### ขั้นที่ 5: คัดลอก Config มาใส่ในไฟล์ `firebase-config.js`
1. กดรูปเฟือง ⚙️ ข้าง **Project Overview** ด้านซ้ายบน → เลือก **Project settings**
2. เลื่อนลงมาที่หัวข้อ **Your apps** → กดไอคอน **`</>` (Web)**
3. ตั้งชื่อแอปเช่น `MintCream Web` (ไม่ต้องติ๊ก Firebase Hosting) → กด **Register app**
4. คัดลอกค่า 6 บรรทัดใน `firebaseConfig` (`apiKey`, `authDomain`, `projectId`, `storageBucket`, `messagingSenderId`, `appId`)
5. เปิดไฟล์ **`firebase-config.js`** ในโฟลเดอร์โปรเจกต์ แล้วนำค่าทั้ง 6 บรรทัดมาแทนที่ข้อความ `"YOUR_..."` แล้วบันทึกไฟล์

### ขั้นที่ 6: เพิ่ม Authorized Domain (หลัง Deploy เว็บเสร็จ)
1. กลับไปที่เมนู **Authentication → Settings → Authorized domains**
2. กด **Add domain** แล้วใส่โดเมนเว็บของคุณ เช่น:
   - ถ้าใช้ GitHub Pages: `your-username.github.io`
   - ถ้าใช้ Netlify: `your-site-name.netlify.app`
3. กด **Add** (หากไม่เพิ่มขั้นตอนนี้ ปุ่มเข้าสู่ระบบ Google จะขึ้นแจ้งเตือนโดเมนไม่ได้รับอนุญาต)

## 3. คู่มือ Deploy ฟรี และวิธีติดตั้ง PWA

### วิธีที่ A: Deploy บน Netlify (ง่ายที่สุด — ลากวาง 1 นาทีเสร็จ)
1. แตกไฟล์ `mintcream-budget-pwa.zip` ให้ได้โฟลเดอร์ `mintcream-budget` (แก้ `firebase-config.js` ให้เรียบร้อยก่อน)
2. สมัครและเข้าสู่ระบบฟรีที่ [Netlify](https://app.netlify.com/)
3. ไปที่หน้า **Sites** → ลากทั้งโฟลเดอร์ `mintcream-budget` ไปวางในกล่อง **"Drag and drop your site output folder here"**
4. รอไม่กี่วินาทีจะได้ลิงก์ HTTPS เช่น `https://mintcream-budget.netlify.app` (สามารถเปลี่ยนชื่อเว็บได้ใน Site configuration → Change site name)
5. นำชื่อโดเมนที่ได้ไปเพิ่มใน Firebase Authorized Domains (ขั้นที่ 6 ด้านบน)

### วิธีที่ B: Deploy บน GitHub Pages (ฟรีถาวร)
1. สมัคร/เข้าสู่ระบบที่ [GitHub](https://github.com/) → กด **New repository** ตั้งชื่อเช่น `mintcream-budget` (เลือก Public) → กด **Create repository**
2. กด **uploading an existing file** แล้วลากไฟล์ทั้งหมดที่อยู่ *ข้างใน* โฟลเดอร์ `mintcream-budget` (`index.html`, `style.css`, `app.js`, โฟลเดอร์ `icons` ฯลฯ) ขึ้นไป → กด **Commit changes**
3. ไปที่แท็บ **Settings** ของ Repository → เมนูซ้ายเลือก **Pages**
4. ในหัวข้อ **Build and deployment → Branch** เลือก `main` และโฟลเดอร์ `/ (root)` → กด **Save**
5. รอประมาณ 1–2 นาที เว็บจะเปิดใช้งานที่ `https://<username>.github.io/mintcream-budget/`

### วิธีติดตั้งเป็นแอป (PWA) ลงหน้าจอหลัก
- **iPhone (Safari)**: เปิดลิงก์เว็บใน Safari → แตะปุ่ม **Share** (สี่เหลี่ยมมีลูกศรชี้ขึ้นด้านล่าง) → เลือก **Add to Home Screen (เพิ่มไปยังหน้าจอโฮม)** → กด **Add**
- **Android (Chrome)**: เปิดลิงก์เว็บใน Chrome → กดปุ่ม **"📲 ติดตั้งแอป"** ที่แถบด้านบนของเว็บ หรือกดเมนูสามจุดมุมขวาบน → เลือก **Install app / Add to Home screen**
- **คอมพิวเตอร์ (Chrome / Edge)**: เปิดลิงก์เว็บ → คลิกไอคอน **ติดตั้ง (หน้าจอมีลูกศรลง)** ที่ปลายขวาของแถบ URL หรือกดปุ่ม **"📲 ติดตั้งแอป"** ในหน้าเว็บ

## 4. รายการเช็กลิสต์ทดสอบ 10 ข้อ (ทำตามได้เอง)

1. **เปิดแอปและตรวจค่าเริ่มต้น**: เปิดหน้าแรกต้องเห็นงบใช้ได้วันนี้, เป้าหมายโน้ตบุ๊ก `฿30,000` (สิ้นเดือน ก.พ. 2027), บิลประจำเดือน `ค่า AI ฿1,000` และ `YouTube ฿130` สถานะ "รอจ่าย" และรายรับประจำสัปดาห์ `฿2,200 + ฿300` สร้างให้อัตโนมัติในสัปดาห์ปัจจุบัน
2. **ทดสอบบันทึกเร็ว (< 5 วินาที)**: กดปุ่ม `+` → ช่องจำนวนเงินโฟกัสทันที → กด `+100` → เลือกหมวด "ค่ากิน" → กดบันทึก → ตรวจว่า Toast แสดงปุ่ม **Undo** 5 วินาที และ "งบใช้ได้วันนี้" ลดลงทันที
3. **ทดสอบ Undo และแก้ไข/ลบ**: กด **Undo** จาก Toast เพื่อย้อนกลับรายการ จากนั้นลองเพิ่มรายการใหม่แล้วแตะที่รายการในหน้าแรกเพื่อแก้ไขจำนวนเงินและบันทึกซ้ำ
4. **ทดสอบกรณีงบวันนี้ติดลบ (โทนสุภาพ)**: ลองใส่รายจ่ายก้อนใหญ่ในวันนี้เกินงบที่เหลือ → ตรวจว่างบใช้ได้วันนี้แสดงเป็น **`฿0`** พร้อมข้อความนุ่ม ๆ *"วันนี้พักก่อนนะ พรุ่งนี้ค่อยว่ากัน 🌿"* โดยไม่มีสีแดงสดหรือป๊อปอัปตำหนิ
5. **ทดสอบบิลประจำรายเดือน**: กดปุ่ม **✓ จ่ายแล้ว** ที่รายการ `YouTube ฿130` → ตรวจว่ารายการถูกบันทึกในประวัติรายจ่ายและหายไปจากกล่องรอจ่ายของเดือนนี้
6. **ทดสอบหน้าเป้าหมาย & What-if**: ไปหน้า **เป้าหมาย** → ลองเลื่อนสไลเดอร์งบโน้ตบุ๊ก (`25,000–35,000`) และลองเลื่อนสไลเดอร์ Shopee / ค่า AI / ค่ากิน ใน **ตัวจำลอง What-if** → ตรวจว่าจำนวนวันที่เร็วขึ้นอัปเดตทันที
7. **ทดสอบ Wishlist & ตั้งเป็นเป้าหมายหลัก**: เพิ่มรุ่นโน้ตบุ๊กที่สนใจ 2 รุ่นในหน้าเป้าหมาย → กด **"ตั้งเป็นเป้าหมายหลัก"** ที่รุ่นหนึ่ง → ตรวจว่าชื่อเป้าหมายและงบเป้าหมายอัปเดตตามราคาของรุ่นนั้นทันที
8. **ทดสอบออมเข้าเป้าหมาย & Milestone**: กด **+ ออมเข้าเป้าหมาย** จำนวน `3,000` บาท (10% ของ 30,000) → ตรวจว่าแถบความคืบหน้าขยับ, จุดแวะพัก `10%` เปลี่ยนสี, และมี Confetti เบา ๆ แสดงขึ้น
9. **ทดสอบสำรองข้อมูล (JSON & CSV)**: ไปหน้า **ตั้งค่า** → กดส่งออก JSON และ CSV → ตรวจว่าเปิดไฟล์ CSV ใน Excel แล้วภาษาไทยอ่านออกไม่เป็นภาษาต่างดาว
10. **ทดสอบซิงก์ข้ามอุปกรณ์ & โหมดออฟไลน์**: (หลังตั้งค่า Firebase) เข้าสู่ระบบ Google เดียวกันทั้งมือถือและคอม → เพิ่มรายการบนมือถือแล้วดูว่าขึ้นบนคอมทันที → ลองปิดเน็ตบนมือถือแล้วเพิ่มรายการ จากนั้นเปิดเน็ตกลับและตรวจว่าซิงก์ขึ้นคลาวด์ครบถ้วน

## 5. สมมติฐานที่ใช้ในจุดที่อาจคลุมเครือ

- **งบกัน Shopee รายเดือนเริ่มต้น**: จากช่วง `1,000–2,500` บาท/เดือน ระบบใช้ค่ากึ่งกลาง **`1,750` บาท/เดือน** เป็นค่าตั้งต้นในสูตรคำนวณงบวันนี้และเครื่องคำนวณความเป็นไปได้ (ปรับแก้ได้ตลอดในหน้า **ตั้งค่า**)
- **ค่ากินเฉลี่ยตั้งต้นก่อนมีข้อมูลจริง**: หากยังไม่มีประวัติรายจ่ายค่ากินครบ 3 รายการขึ้นไป เครื่องคำนวณความเป็นไปได้จะใช้ค่าเริ่มต้น **`950` บาท/สัปดาห์** และค่าน้ำมัน **`300` บาท/สัปดาห์** เมื่อคุณเริ่มจดรายจ่ายจริง ระบบจะคำนวณจากค่าเฉลี่ยจริงให้อัตโนมัติ
- **จำนวนสัปดาห์ต่อเดือน**: ใช้ค่ามาตรฐานปฏิทิน `4.345` สัปดาห์/เดือน (`365 ÷ 12 ÷ 7`) เพื่อให้การแปลงรายจ่ายรายเดือนเป็นส่วนแบ่งรายสัปดาห์แม่นยำกว่าการหาร 4
- **โหมดใช้งานก่อนตั้งค่า Firebase**: หากไฟล์ `firebase-config.js` ยังเป็นค่าตัวอย่าง `YOUR_...` แอปจะเปิดใช้งานใน **โหมดเก็บข้อมูลบนเครื่อง (Local Mode)** อัตโนมัติ เพื่อให้คุณเปิดทดลองใช้งานได้ทันทีโดยไม่ติดหน้า error
